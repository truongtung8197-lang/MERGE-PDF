PDF Merger Tool 📄🔗

Một ứng dụng Python đơn giản, có giao diện đồ họa (GUI) giúp bạn ghép (merge) nhiều file PDF lại thành một file duy nhất một cách nhanh chóng và dễ dàng.

🌟 Tính năng

Giao diện trực quan: Thao tác dễ dàng thông qua GUI.

Ghép nhiều file PDF: Chọn và hợp nhất các tệp PDF chỉ với vài cú nhấp chuột.

Nhanh chóng & An toàn: Xử lý hoàn toàn trực tiếp trên máy tính của bạn (offline), không lo lộ dữ liệu.

🚀 Hướng dẫn cài đặt & Sử dụng

1. Yêu cầu hệ thống

Đã cài đặt Python trên máy tính.

2. Cài đặt các thư viện cần thiết

Mở Terminal (hoặc Command Prompt / PowerShell) và chạy lệnh sau để cài đặt các thư viện phụ thuộc (nếu có):

pip install -r requirements.txt


(Lưu ý: Nếu repo chưa có file requirements.txt, hãy đảm bảo bạn đã cài các thư viện giao diện và PDF tương ứng, ví dụ: pip install PyPDF2 tkinter hoặc thư viện bạn đang sử dụng).

💻 Cách chạy chương trình

Để khởi chạy giao diện ứng dụng, bạn chỉ cần mở terminal tại thư mục dự án và chạy lệnh:

python main.py


📖 Hướng dẫn sử dụng trên giao diện

Chạy lệnh python main.py để mở ứng dụng.

Nhấn nút chọn các file PDF bạn muốn ghép.

Sắp xếp thứ tự các file (nếu có tùy chọn).

Nhấn nút Merge / Ghép file và chọn nơi lưu file PDF kết quả.
